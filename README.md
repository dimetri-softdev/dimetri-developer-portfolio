# Dimetri Peters — Developer Portfolio

A responsive dark-themed React + Vite portfolio starter.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open it in VS Code.
3. Open the terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Deploy on Render

1. In Render, choose **New > Blueprint** and connect this repository.
2. Select the `main` branch. Render will use `render.yaml` to create the static site.
3. When the deployment finishes, open the `onrender.com` URL shown in the Render dashboard.

Render rebuilds the site automatically whenever changes are pushed to `main`.

## Personalise before publishing

- Keep the featured projects, descriptions, and technology lists aligned with your CV.
- Update repository links when project repositories change.
- Add or update contact and professional profile links as needed.

## Stack

- React 18
- Vite 6
- Lucide React icons
- Custom responsive CSS
